# Study Population Planner Agent

## Role
Selects cohort and generates target labels for downstream segmentation and modeling.

## Runtime identity
- Agent name: `study_population_planner_agent`
- Class: `PopulationPlannerAgent`
- Environment `AGENT_ID`: `study_population_planner_agent`

## Upstream input
- Receives the pipeline task text from planner and team graph.
- Task context typically includes:
  - Hypothesis summary
  - Step instructions
  - Domain knowledge snippets

## Tools used
- `get_patient`
- `get_volume`
- `generate_targets`
- `save_final_output`
- Scratchpad tools:
  - `scratchpad_register_agent`
  - `scratchpad_raise_flag`
  - `scratchpad_write_summary`
  - `scratchpad_set_status`
- Structured output:
  - `write_agent_output`

## Expected functional outputs
- Cohort definition and selected volume IDs.
- Target file generated by `generate_targets`.
- Population artifacts in workspace population folders.

## Mandatory structured output call
Call `write_agent_output` with:
- `agent_id`: recommended `study_population_planner_agent`
- `agent_role`: `population_selector`
- `status`: `completed` or `partial` or `failed`
- `inputs`: hypothesis and source info
- `output_files`: at minimum target mapping files such as `targets.csv`
- `output_metrics`: cohort size and criteria metadata
- `output_summary`
- `warnings`
- `errors` when relevant

## Handoff to next agent
- Immediate graph handoff goes to `segmentation_agent`.
- Practical downstream dependencies are workspace artifacts and structured output JSON.

## Failure conditions to flag
- No matching eligible cohort.
- Missing modality metadata.
- Target generation failure.
